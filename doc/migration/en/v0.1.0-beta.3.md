# Migrating to v0.1.0-beta.3

Applies when upgrading from `v0.1.0-beta.2`. Only changes that affect an existing
configuration or operator expectation are listed; per-release files live beside this one.

## 1. Before you upgrade

| Change | What to do |
| --- | --- |
| A parent in `lan_interface` or `wan_interface` (for example `eth1`) now skips frames still tagged with a non-zero VLAN ID, so direct and block rules written for that subnet stop applying to it, and nothing logs or reports that. VID 0 priority tags are unchanged. | List the VLAN device (`eth1.20`, or `br0.N` on a VLAN-aware bridge) to manage that subnet. Without this, the subnet is forwarded or answered natively. |
| Third-party TCX programs ordered after honk and legacy `clsact`/`cls_bpf` filters on the same device now see non-zero-VID tagged frames and unclassified non-IP or unsupported-L4 frames. Flows over an upper device such as `macsec0` listed in `lan_interface` are now classified. | Nothing for honk itself. |
